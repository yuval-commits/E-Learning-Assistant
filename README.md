# 🎓 E-Learning Doubt Clearing Assistant

An AI-powered tutoring assistant that provides context-aware answers to student questions within an online course.

## 🚀 Features

- Context-based doubt resolution
- Step-by-step explanations
- Example generation
- Practice question suggestion
- Confidence scoring
- Downloadable responses
- Clean animated UI

## 🧠 How It Works

The tool uses Google Gemini to:
- Analyze lesson content
- Understand the student's question
- Generate structured explanations
- Provide guided learning support

## 🛠 Tech Stack

- Python
- Streamlit
- Google Gemini API

## 🌍 Deployment

Add API key in Streamlit Cloud:

App → Settings → Secrets
